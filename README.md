# Order Testing Project

Почетни пројекат за практични дио дипломског рада:

**„Методе јединичног тестирања у C++ језику коришћењем
Google Test и Google Mock алата“**

## Сврха пројекта

Пројекат представља дјелимично имплементиран систем за обраду
наруџби у интернет продавници.

Студент добија:

- структуру CMake пројекта;
- декларације класа и интерфејса;
- потпуно имплементирану класу `Product`;
- дјелимично имплементирану класу `Cart`;
- један једноставан тест;
- један примјер mock класе;
- списак функционалних захтјева.

Преостале функционалности означене су коментаром `TODO`.

## Захтјеви

- C++17 компајлер;
- CMake 3.16 или новији;
- Google Test и Google Mock;
- Python 3, опционално за анализу тежине тестирања.

## Компајлирање без тестова

```bash
cmake -S . -B build -DBUILD_TESTS=OFF
cmake --build build
```

## Компајлирање са тестовима

Google Test и Google Mock морају бити доступни CMake систему.

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
```

## Покретање тестова

```bash
ctest --test-dir build --output-on-failure
```

## Задаци за студента

1. Анализирати структуру и захтјеве система.
2. Имплементирати методе означене са `TODO`.
3. Написати тестове за све јавне функционалности.
4. Тестирати `OrderService` са стварним зависностима.
5. Креирати преостале mock класе.
6. Тестирати `OrderService` помоћу Google Mock-а.
7. Упоредити тестирање са и без mock објеката.
8. Измјерити покривеност кода.
9. Оцијенити тежину тестирања функција.
10. Документовати резултате.

## Напомена

Неимплементиране методе бацају `std::logic_error`.
То је намјерно урађено како би се јасно разликовале
имплементиране и неимплементиране функционалности.
